# AI Agent 教師研習簡報

給高中非資訊科教師的 AI Agent 入門研習簡報。單一 HTML 檔，用瀏覽器打開即可播放。

目前有兩份，主軸不同，可以擇一，也可以先概念後操作連著開兩場。

| 檔案 | 版本 | 時數 | 場地 | 主軸 |
|---|---|:--:|---|---|
| `index.html` | **3 小時速成版** | 3hr | 電腦教室 | **操作**：把生成教材做成技能 |
| `concept.html` | **概念入門版** | 2hr 或 3hr | 講述版任何場地／實作版電腦教室 | **概念**：從「會聊天」到「會做事」 |

兩份簡報的最後一頁互相連結。

## 播放

打開簡報網址，按 `F` 全螢幕即可上台。

| 按鍵 | 動作 |
|---|---|
| `→` `↓` `空白` | 下一頁 |
| `←` `↑` | 上一頁 |
| `Home` / `End` | 第一頁 / 最後一頁 |
| `F` | 全螢幕 |
| `E` | 匯出當前頁 2× PNG |
| `N` | 顯示／隱藏講者備忘稿（兩份簡報皆有；**投影前記得關掉**） |
| `R` | 揭曉本頁所有互動內容（僅概念入門版） |

也可以點畫面右側 30% 下一頁、左側 30% 上一頁（觸控與簡報筆友善）。

## index.html｜3 小時速成版（28 頁）

**把生成教材做成技能。** 三小時只有一條線 —— 先講清楚 → 做一次 → 把它變成永久的。
散場時每位老師手上有一份考卷、一整包教材，以及一個能重複觸發、可以複製給同事的技能。

| 段落 | 頁 | 內容 |
|---|---|---|
| 引起動機 | 1–4 | 痛點 → 代理 vs 生成 → 今天的路線 |
| S1 先講清楚，再讓它做 | 5–13 | **Agent 關係圖**、專案與路徑、**在你電腦上跑≠資料沒離開**、三條安全底線、**交辦四問**、需求探索四象限、讓 AI 直接問你、實作①出一份考卷 |
| S2 做過一次，就讓它變成你的 | 14–25 | 一份教材長出一整包、Bloom 分層（含**貼標籤檢查**）、**桌面上的東西從哪來**、**一份教材五種成品**、**先用別人寫好的技能（安裝六個）**、**實作②公布欄圖卡**、**簡報交 .pptx 還是 .html**、技能是說明書、對話型 vs 檔案型、說明書六個欄位、實作③包成技能 |
| 喚起行動 | 26–28 | 評分看什麼、回校後會撞到的三件事、進修順序與**下一場預告** |

**2026-09-15**：24 → 25 頁。從概念入門版摘錄三頁精華（P6 關係圖、P8 個資、P17 桌面圖），以**合併舊頁**取代而非加頁；
唯一新增的是 P18「先用別人寫好的技能」——照 [ppsh-agent-basics-packs](https://github.com/frentexx/ppsh-agent-basics-packs) 的 02 安裝開工／收工技能，打開 SKILL.md 再接「技能就是說明書」。

### 四個互動元件

- **P10 交辦四問**：點卡片看「漏掉會怎樣」。四問是把需求交出去的格式，四象限是問出需求的工具
- **P11 需求探索四象限**：點卡片展開。建議現場一格一格點開，第三、四象限留到最後
- **P16 Bloom 分層對比表**：點欄位標題可排序，含一欄「假分層的樣子」
- **P26 評分雷達圖**：對比「只顧做出來」與「做出來且檢查過」

### P12 是給學員直接貼上用的

第 12 頁放了一則**可以直接複製的提問指令**，讓 AI 照四象限反問學員，
最後一句「問完就停」就是停點示範。學員把答案整理成 `需求清單.md`，
這份清單是 S1 實作的指令來源，也是 S2 技能說明書的骨架 —— 四象限與技能之間的那條線就在這裡接起來。

## concept.html｜概念入門版（45 頁）

**一份母本，兩種開法。** 2 小時講述版任何場地都能跑；3 小時實作版在電腦教室，
每個活動區塊多一段學員自己動手。

| 模組 | 頁 | 分鐘 | 學員要帶走的一句話 |
|---|---|:--:|---|
| 開場 | 1–4 | 10 | AI 不是變聰明了，是被裝上了手腳 |
| **M1 五個詞的關係** | 5–18 | 53 | Agent = 腦袋 + 桌面 + 交接本 + 工具 + 制度 |
| M2 把「你是誰」寫進設定 | 19–23 | 19 | 講第三次的話就該寫進設定 |
| M3 交辦四問 | 24–29 | 27 | 沒講停點，它就會一路做到底 |
| **M4 邊界、驗收與責任** | 30–38 | 33 | AI 沒有責任，你有 |
| 收尾 | 39–45 | 17 | **決定權在人，責任也在人** |

**2026-09-12 改版**：34 → 43 頁，講述版 120 → **166 分鐘**（含 10 分休息），實作版 180 → **210 分鐘**。
新增的重點是原本缺的那幾塊：**本機權限三層、提示詞注入、規則層與執行層的差別、

**2026-09-15 資訊圖表**：P8、P10、P17、P20、P25、P32、P36、P39 改為內嵌資訊圖表（純 SVG，元件顏色走 CSS 變數，文字與原版一致）。

### 六個互動元件

- **P6 五個詞卡片**：點卡片展開定義，建議一個一個開
- **P12 畫面上哪些是 Harness 做的**：點列揭曉答案，**全課最能破除「AI 很神」迷思的一頁**
- **P18 八個怪現象**：點列揭曉真正原因與該動哪一層
- **P27 同一任務三個版本**：點 A／B／C 切換，看多寫的兩行擋掉了什麼
- **P31 不以人為本長什麼樣**：點卡片展開三種反例（直接放行／橡皮圖章／判斷外包），橡皮圖章附批改學習單的實例
- **P37 驗收檢查表**：點一項勾一項，可當現場小卡

按 `R` 可以一次揭曉本頁全部答案（趕時間時用）。

## 設計

- 林長揚 30 原則：字級階層、標題 ≤10 字、一頁一重點、強調色僅 2 種
- SOIL 三段式脈絡，左上角即時顯示當前段落
- 8px 基線網格
- 版面驗收：1600×900 與 1366×768 兩種解析度，兩份簡報在「互動元件全部展開」的狀態下皆零溢出
- 全向量 SVG，無外嵌點陣圖

## 需要網路

`E` 鍵匯出 PNG（html-to-image）、速成版雷達圖（Chart.js）與字體（Google Fonts）走 CDN。
場地無網路時仍可正常播放與翻頁，但上述三項會失效。
